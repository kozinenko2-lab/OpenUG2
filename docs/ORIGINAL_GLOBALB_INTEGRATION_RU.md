# Оригинальный GlobalB.lzc из NFS Underground 2

Эта ветка работает **только с данными оригинальной ПК-версии Underground 2**.
Ранее присланный несжатый `GlobalB.lzc` с записями размером `0xC90`
относится к другой игре (вероятнее всего NFS Underground 1), поэтому
он исключён из активной разработки. Любые расширения трафика из него
не переносятся.

## Источник

- В пользовательской Library оставлен один исходный архив: `GlobalB.zip`.
- `GlobalB_.zip` — байтовый дубликат вложенного `GlobalB.lzc` — удалён из Library.
- Неверный файл `GlobalB.lzc` (модификация для Underground 1) удалён из Library.
- Вложения EA **не загружаются в GitHub**. Рабочие данные остаются локальными.
- Контроль SHA-256 вложенного оригинального `GlobalB.lzc` из архива
  пользователя: `39751a62a1c6a303aa20122afe847af4a8a81c995e9d79c369fb73043261f4d7`.
  **Не** требовать этот SHA от других легальных региональных изданий.

## Что уже реализовано

- `src/ug2_career_file.c/.h`: загрузка исходного JDLZ и ограниченная
  по размеру распаковка без чтения за пределами буферов, разбор верхних
  секций `GlobalB` и обоих `CareerManager` (`0x80034A10`).
- Для каждого `CareerManager` используется валидатор записей
  `src/career_source_catalog.c` (форматы, восстановленные по MIT
  `NFSTools/GlobalLib`). Обнаруженные повреждения ведут к отказу без
  частичного изменения выходного каталога.
- Повторные идентификаторы гонок внутри различных секций объединяются.
  Конфликт стадии, приза или количества оппонентов с одинаковым ID считается
  ошибкой данных. Каждому уникальному событию сохраняется его источник-секция.
- `tools/ug2_career_file_test.c`: тесты на синтетических записях,
  частичном/искажённом контейнере, повторе и конфликте гонок, JDLZ-файле.
- `tools/ug2_career_dump.c`: отдельная диагностическая команда,
  которой разрешается читать **только локально установленные** игровые файлы.
  Результат не отправлять в GitHub как игровую базу.

## Проверено на предоставленном оригинале

Общий размер JDLZ: 5 145 778 байт. Размер распакованного контейнера:
8 008 064 байта.

- `CareerManager`: 2 секции
- Записей гонок: 232 (уникальных ID: 225; повторов: 7)
- Записей этапов: 8 (включая вспомогательный вариант 0/1)
- Записей спонсоров: 20

Это подтверждает корректность нового *каталожного* загрузчика, **но не**
полную карьеру. Например, считывание поля выплаты не доказывает, что
гонку можно провести и честно завершить на данном этапе движка.

### Запуск локального аудита

После установки C toolchain на Linux:

```bash
make ug2-career-file-test
make ug2-career-dump
# Использовать свой оригинальный файл, распакованный из GlobalB.zip:
./build/ug2_career_dump "/path/to/NFS Underground 2/GLOBAL/GlobalB.lzc"
```

Результат содержит имена событий и значения полей из игры —
не включайте его в публичные коммиты.

## Дальше для полноценной карьеры

1. Сопоставить каталожные ID и маршруты с реально запускаемыми
   городскими событиями (нельзя путать `EV_...` с race ID).
2. Считать авторскую награду по подтверждённому ID **после** честного
   финиша со всеми соперниками, сохранить баланс и уникальную победу.
   Убрать временные 500 кредитов только после такого сопоставления.
3. Перенести условия `GCareerStage` и `Sponsor`, спонсорские гонки,
   реальные требования открытий и сюжетный переход.
4. Связать гараж v2 с выбором автомобиля и покупками, применить
   фактические модификации в физике и графике.
5. Отдельно проверить все гонки, прохождение и сохранения на H700.

Техническая платформа: RG40XX H / Allwinner H700 / ARM64 / SDL2 /
OpenGL ES2 / PortMaster / 1 ГБ RAM. CI на Ubuntu ARM64 не заменяет
тестирование на устройстве.
