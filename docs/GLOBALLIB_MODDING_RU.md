## Что подтверждено в GlobalLib

- Это библиотека **C# (.NET Framework v4.6, Windows Presentation Foundation,
  Windows Forms и DevILNet)**, а не готовый двоичный ARM64-редактор для H700.
- Читает/пересобирает `GlobalB.lzc` и `GCareer`. Реализованы
  `GCareerRace`, `GCareerStage`, спонсоры, `WorldShop`, `CarTypeInfo`,
  `PresetRide`, TPK и ряд других секций.
- Сохранение работает через `SaveGlobalB.cs` и `CareerManager.Assemble.cs`.
  Последний пересобирает строки, блоки, смещения и выравнивание.
- Нельзя просто запустить эту .NET Framework DLL на Mali H700/MuOS без
  совместимого .NET, GDI/WPF и Windows-зависимостей. Не тащим их в порт.
- Не используем части поддержки Underground 1: они не совместимы с UG2.

## Первый прототип лёгких модов на устройстве

Native C99 модуль `src/ug2_career_mod.c/.h` читает **не более 64 КБ**
конфигурации из `mods/career.cfg`:

```text
# Изменяем только существующее событие с точным оригинальным ID
cash S3_SPRINT_6 2000
```

Для теста/просмотра на ПК:
```bash
make ug2-career-file-test ug2-career-mod-test ug2-career-dump
./build/ug2_career_dump "/path/to/UG2/GLOBAL/GlobalB.lzc"
./build/ug2_career_dump "/path/to/UG2/GLOBAL/GlobalB.lzc" "mods/career.cfg"
```

Для RG40XX H: скопировать
`portmaster/openug2/mods/career.cfg.example` в `mods/career.cfg`
и отредактировать. Лаунчер PortMaster автоматически добавляет опцию
`--career-mod` без второго `.sh`. Когда опция задана, игровой
движок считывает **оригинальный локальный** `GLOBAL/GlobalB.lzc`,
проверяет корректность настроек, имена событий, диапазон наград
0..10 000 000, отсутствие дублей и ошибок, не изменяя копию игры.
При любой ошибке весь пакет отклоняется атомарно.

**Текущий статус:** настройки применяются в оперативной памяти к
карьерному **каталогу**, их можно проверить утилитой или сообщением
в логах при старте. В рабочем игровом цикле сумма начисления
пока остаётся прежней (прототипные 500 за честную circuit-победу):
настоящее сопоставление ID каталога и игрового маршрута
ещё не реализовано. Не обещаем реального изменения денежных наград
до такого сопоставления.

## Как ускорить следующие модификации

1. Подключить сопоставление оригинальных race ID и заездов OpenUG2;
   начислять награду по каталогу, *только* после подтверждённой победы.
2. Перенести в безопасный C sidecar-формат параметры спонсоров, unlock и
   магазинов (при этом валидировать зависимости между данными).
3. Использовать Windows/PC GlobalLib **офлайн** для комплексных модов
   (`GlobalB.lzc` + TPK + магазины + гараж), создавая отдельную
   модифицированную копию игры и сохраняя оригинал.
4. Отдельный ПК-конвертер GlobalLib -> OpenUG2 JSON/modpack и опциональный
   редактор с GUI для редактирования таблиц без ручной правки бинарников.

Никакие оригинальные игровые ресурсы, чужие библиотеки и готовые
модифицированные `GlobalB.lzc` не добавляются в GitHub.
