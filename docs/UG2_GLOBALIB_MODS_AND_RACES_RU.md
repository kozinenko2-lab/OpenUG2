# Реальные события карьеры и простые моды на базе GlobalLib

Первоисточник форматов: [NFSTools/GlobalLib](https://github.com/NFSTools/GlobalLib)
(MIT License, © MaxHwoy & NFS Tools). У библиотеки есть C#-сериализаторы
`GCareerRace`, `GCareerStage`, `Sponsor` и `CareerManager`.
**Мы не переносим редактор .NET внутрь H700**: тяжёлый managed runtime не нужен
для игры с 1 ГБ RAM. Вместо него в движок интегрирован небольшой C99-читатель
оригинальных данных и безопасный слой модификаций.

## Сейчас работает

1. Читатель оригинального `GLOBAL/GlobalB.lzc`, включая JDLZ и два
   `CareerManager`. Пример пользовательского оригинала:
   232 записи гонок / 225 уникальных идентификаторов (без игровых файлов в Git).
2. Маршруты событий карты из `world.city.ev[].id` сопоставляются с
   `GCareerRace.track_ids[]` для текущего этапа. Имена `Paths####.bin`
   идентифицируют ту же самую трассу. В лог выводится количество событий
   карьеры на каждом маршруте. **Сопоставление маршрута не означает**, что
   все его гонки автоматически доступны или пройдены.
3. Для результата **только** поддерживаемого кольцевого заезда с реальными
   соперниками проверяются: первое место, этап, номер маршрута, тип
   оригинального события, число кругов, число соперников.
   Поле `EventBehaviorType` проверяется как `Circuit=0`, `IsHiddenEvent=0`.
   При запуске проверенного **уже открытого** события исходные `laps[0]` и `opponents`
   задают длину заезда и число действительно симулируемых AI; тестовый
   четвёртый AI не засчитывается как оригинальный соперник.
4. Скрытые кольцевые гонки с `IsHiddenEvent=1` теперь не засчитываются:
   для них ещё не восстановлены условия появления/разблокировки.
   Аналогично оригинальная игра может иметь разные гонки на одном маршруте.
   Если один маршрут принадлежит нескольким событиям текущего этапа,
   при отсутствии точного `--career-race ID` награда **не начисляется**.
   Пользователь может выбрать конкретный ID из своего каталога.
5. Источник денежной награды — `GCareerRace.cash_value`. Больше нет
   безусловных 500 кредитов за любую тестовую трассу. Пройденное
   событие пишется в наш `saves/career.dat` ровно один раз даже при
   смене зоны карты.
6. Продвижение этапа *по временным счётчикам* отключено в новой ветке
   начисления настоящих выплат: для продвижения ещё предстоит подключить
   реальные спонсорские, URL, обложки и финальные гонки.

## Строгая проверка исходных условий открытия (новая итерация)

Проверено по открытому исходнику GlobalLib
`GlobalLib/Reflection/Enum/eUnlockCondition.cs` и предоставленному
**оригинальному** `GlobalB.lzc` для Underground 2:

| Код | Значение GlobalLib | Поведение в порту |
|---|---|---|
| 0 | `SPECIFIC_RACE_WON` | Пока **заблокировано**: необходима проверенная связь хэша предыдущего события с победой |
| 1 | `AT_STAGE_START` | Допускается при совпадении исходного маркера этапа (байт +0x10 = stage−1), отсутствии дополнительных требований |
| 2 | `SPONSOR_CHOSEN` | **Заблокировано** до полноценной системы контрактов |
| 3 | `REQUIRED_RACES_WON` | **Заблокировано** до учёта оригинальных побед и счётчиков |
| 4 | `REQUIRED_URL_WON` | **Заблокировано** до завершения URL-гонок |

Все эти условия должны проверяться **даже при точном**
`--career-race ID`. Это проверка для **поддерживаемых обычных кольцевых
заездов**, а не универсальная реализация всех сценариев. Мы **не
присваиваем** классам Drift, StreetX, Drag или URL возможности Circuit.

Из предоставленного оригинала выяснено: кольцевая гонка первого этапа
`STAGE_1_CIRCUIT_1` имеет условие `SPECIFIC_RACE_WON` с хэшированной
зависимостью. Поэтому теперь **не начисляется**, пока не будет
восстановлена подтверждённая предшествующая гонка/пролог. Это временно
ограничивает прохождение первого этапа, но устраняет ложную возможность
получить деньги за ещё заблокированный оригинальный заезд.

Проверено, что обычные открытые кольцевые гонки этапов 2–5 в этом
оригинале имеют `AT_STAGE_START` с индексами 1–4 соответственно.
Другие издания игры/модификации должны пройти такую же проверку, иначе
выплата отклоняется.

Регрессии: `make ug2-career-binding-test`,
`make ug2-career-credit-test`. Состояние профиля и файлы сохраняются
без изменений, если исходный unlock-гейт не подтверждён.

### Следующая короткая итерация

Восстановить цепочку `SPECIFIC_RACE_WON`: вычисление хэшей по
оригинальному алгоритму игры, сопоставление хэшей с авторскими ID и
проверка `career_has_win()`. После этого открыть и протестировать
стартовое событие без обхода условий. Для спонсорских/URL условий
понадобится отдельный механизм подтверждения побед и договора.

## Проверенная транзакция завершения гонки

В `src/ug2_career_credit.c/.h` результат кольцевой гонки проходит через
одну атомарную по состоянию профиля операцию:

- Проверка подтверждённого 1-го места, числа соперников и кругов;
- Разрешение одного **оригинального**, не скрытого, события
  `GCareerRace` с проверкой стадии, типа, номера маршрута и ID;
- Отклонение неоднозначных общих трасс и повторных выигрышей по
  оригинальному ID независимо от района карты;
- Зачисление строго `cash_value` из уже валидированного каталога
  (с учётом разрешённой пользовательской надстройки);
- **Сначала** запись `saves/career.dat` с проверкой результата,
  **только потом** обновление профиля в оперативной памяти.

Если диск недоступен или сохранение не получилось, память профиля
остаётся прежней, и игрок не теряет начисление при завершении игры.
Тесты `make ug2-career-credit-test` моделируют два события на одном
маршруте, повторную победу, неверный тип, скрытые гонки, второе место
и ошибку записи без ресурсов EA.

Это надёжность сохранения, **не** реконструкция всех сюжетных
разблокировок. В следующем этапе всё ещё необходимо восстановить
условия спонсоров и журналов, а также проверить физический финиш
с оригинальными контрольными точками.

## Как тестировать кольцевую гонку

В Linux (или через настройки `OpenUG2.sh` на H700), с собственными файлами ПК:

```bash
./nfsu2 /path/to/NFSU2 \
  --career-save /path/to/saves/career.dat \
  --track STREAML4RA \
  --circuit ROUTESL4RF/Paths4081.bin \
  --career-race S3_CIRCUIT_10
```

Для стартовой кольцевой гонки первого этапа оригинальный каталог
содержит: `STAGE_1_CIRCUIT_1`, маршрут `Paths4013.bin`, **3 круга,
3 соперника и 250 кредитов**. Выбор соответствующего `--career-race`
позволяет движку выставить оригинальные круги и количество AI, если
такая трасса действительно доступна в текущей копии игры.

Это **пример связи ID и маршрута**, а не обещание немедленной награды:
исходное событие находится в этапе 3, использует 2 круга и 3 соперников.
При старте нового профиля текущий этап равен 1 — его разблокировка в
настоящем игровом процессе ещё не реализована. Результат гонки также
может зависеть от незаконченной логики AI или кругов.

Если подходящего `GLOBAL/GlobalB.lzc` нет, или условия не доказаны,
начисления нет — игра не подменяет их искусственными выплатами.

## Модификация наград без редактирования оригинальных архивов

В папке игры создать `mods/career_rewards.cfg`:

```ini
# cash overrides by exact original career race name
S3_CIRCUIT_10=450
S3_CIRCUIT_11=700
```

Скрипт PortMaster подхватывает этот файл автоматически, если он существует.
На обычном Linux можно указать `--career-mod /path/to/career_rewards.cfg`.

Проверки: ASCII имена строго соответствуют исходному каталогу,
выплаты — целые 1..1000000, дубли/неизвестные имена/повреждённые
файлы запрещены. **Атомарность:** один ошибочный пункт отменяет весь
мод. Оригинальный `GlobalB.lzc` и прочие игровые ресурсы не изменяются.
Если файл отсутствует или неверен, используются оригинальные цены.

Это первый практический слой моддинга. Следующий шаг —
поддержка авторских unlock-флагов, новых машин и способов открытия
событий в отдельном формате, с независимыми тестами.

## Ограничения

- Не реализован полный сюжет и все типы заездов, не проверена
  физическая H700 консоль с загруженным оригиналом.
- Неподдержанные спонсорские, URL, drift/drag/sprint и особые события
  не могут начисляться как кольцевые гонки.
- Глобальный каталог содержит несколько событий на одной трассе:
  карта покажет их число, но должна появиться система выбора реального
  события и его разблокировки по оригинальным условиям.
- Количество кругов и активных AI-соперников для распознанной кольцевой
  гонки выставляется из оригинальной записи (например, стартовый
  `STAGE_1_CIRCUIT_1` — трасса 4013, три круга, три соперника).
  На обычных заездах без проверенного ID сохраняются прежние значения.
- Начисления всё ещё зависят от фактического работающего финиша
  исходного AI-режима; прохождение полного этапа не протестировано.
- Имеющиеся игровые сохранения OpenUG2 — отдельный формат, это не
  оригинальные файлы сохранений EA.
