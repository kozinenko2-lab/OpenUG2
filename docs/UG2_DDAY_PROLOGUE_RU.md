# OpenUG2 / H700: пролог DDAY — независимая регистрация (итерация 16)

## Проверено на оригинальном GlobalB.zip пользователя

Из единственного `GlobalB.lzc` (JDLZ: 5 145 778 -> 8 008 064 байт) извлечены **оба** оригинальных блока CareerManager. Авторские данные (двойные записи в разных блоках проверены отдельно):

| Поле | DDAY_EVENT_A | DDAY_EVENT_B | STAGE_1_CIRCUIT_1 |
|---|---:|---:|---:|
| Retail stage | 0 | 0 | 1 |
| TrackID | 4000 | 4000 | 4013 |
| Behavior | 3 | 3 | 0 (circuit) |
| Opponents / laps | 0 / 0 | 0 / 0 | 3 / 3 |
| CashValue | 0 | 0 | 250 |
| Unlock method | 0 | 0 | 0 |
| Predecessor hash | 0 | 0xdd60e402 (DDAY_EVENT_A) | 0xdd60e403 (DDAY_EVENT_B) |

Эти **метаданные не доказывают**, что `behavior=3` реализован текущим OpenUG2 как оригинальная сценка. Текущий World/AI circuit finish не умеет подтверждать нулекруговые события на общем маршруте 4000.

## Код

- `ug2_career_prologue.[ch]`: строго идентифицирует обе записи оригинала, проверяет цепочку A → B и наличие подтверждённой записи в текущем профиле. Дубли и испорченные записи запрещают применение.
- `career_record_original_prologue()`: сохраняет канонический ключ в `Career.wins[]` без денежных выплат, соперников, фиктивного прогресса этапа, изменения `total_wins` или `world_wins`. Формат сохранения v2 прежний.
- `ug2_prologue_record_verified_finish()`: атомарная транзакция «сохранить копию → опубликовать RAM», только для допустимого оригинального события с маршрутным ID 4000 при подтверждённом **отдельной системой** завершении сценария.
- В живом `main.c` теперь логируется состояние DDAY A и B (заперт / готов принять *подтверждённый* сценарный результат / уже записан / плохой каталог). **Живой код НЕ вызывает функцию завершения автоматически**.
- `tools/ug2_prologue_test.c`: синтетические проверки цепочки, чужого/неподтверждённого финиша, некорректного маршрута, недоступного этапа, пропажи каталога, повторов, отката при ошибке сохранения, восстановления из файла и разблокировки оригинального кольца 4013 после A и B.
- Новая цель `make ug2-prologue-test` включена в ARM64/GLES2 GitHub Actions.

## Безопасность

Нельзя превращать `--event 4000`, касание чекпойнта, `--career-race DDAY_EVENT_B` или простой флаг «маршрут завершён» в доказательство A/B: оба события используют один и тот же маршрут с нулём кругов и соперников. Начисление денег за это было бы ошибкой. Нельзя считать `DDAY` победами для достижения обычных порогов этапа. Оригинальные ресурсы и собственные файлы переводов/модов в репозиторий не включены.

## Следующий блок

Восстановить отдельное авторитетное прохождение сценария в оригинальном порядке (с обработкой начальной сцены, позиций игрока, условий окончания и различения A/B). Только после такого подтверждения подключить `ug2_prologue_record_verified_finish()` к runtime. До этого чистый профиль всё ещё не может пройти DDAY автоматически. Физический тест на Mali H700 пока не выполнен.
