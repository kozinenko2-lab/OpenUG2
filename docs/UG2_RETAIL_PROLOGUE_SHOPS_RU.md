# OpenUG2: оригинальные WorldShop-триггеры пролога (итерация 17)

## Источник

Пользовательский **оригинальный** PC `GlobalB.zip/GlobalB.lzc`, JDLZ:
5 145 778 → 8 008 064 байт. Проверены два вложенных CareerManager;
в каждом 24 записи `SHOP_BLOCK=0x00034A12` размером 0xA0 байт.

Сопоставление полей с MIT-реализацией NFSTools/GlobalLib
`Support.Underground2/Gameplay/WorldShop/Functional/Disassemble.cs`.
Сторонние бинарники EA, ролики, карты и modded GlobalB в GitHub не добавлялись.

## Проверенные записи

- Секция 0: `CC_CAR_LOT_1`, type 4 (=CARLOT), stage 0, initially hidden 0,
  `SCENE05`, файл `CARLOT01.BIN`, raw trigger hash `0xFFCC6A4B`.
  Значение совпадает с NFS Binary Hash для `TRIGGER_CC_CAR_LOT_1`.
- Секция 0: `CRIB_1`, type 0 (=CRIB_GARAGE), stage 0,
  `SCENE06`, файл `CRIB01.BIN`, `unlocked_by_event=1`,
  required event `0xDD60E402` = `DDAY_EVENT_A`.
  `trigger_key=0xF98D0C92` — **не** выдавать за известную координату.
- Секция 1 содержит **другую версию** `CC_CAR_LOT_1` со stage 0 и
  `initially_hidden=1`. Следовательно, нельзя молча удалять дубликаты
  магазинов из двух секций и выбирать произвольно «правильную» видимость.
- Ранее проверенная цепочка гонок остаётся A → B → STAGE_1_CIRCUIT_1.
  `DDAY_EVENT_A/B`: stage 0, общий TrackID 4000, OpenWorld (enum 3),
  без противников, кругов и денежных наград.

## Что изменено в исходном коде

- `src/ug2_career_file.h`: структура `UG2CareerShop`,
  максимум 128 магазинных записей и сохранение номера исходной секции.
- `src/ug2_career_file.c`: проверка длины блока, границ и строк,
  enum магазина, булевых полей и дублей **внутри** одной секции.
  Парсер не переводит raw stage в 1–5: оригинальные записи имеют stage=10.
  Повреждённый блок оставляет исходный индекс неизменным.
- `src/main.c`: диагностический лог оригинального автосалона и гаража,
  включая trigger hash, event gate, фильм, видимость и исходную секцию.
- `tools/ug2_career_dump.c`: локальный инструмент показывает
  исходные shop-записи без загрузки графики.
- `tools/ug2_career_file_test.c`: синтетические тесты двух
  секций с отличающейся видимостью, проверка event gate и отказ
  от испорченного типа без частичного изменения индекса.

## Почему DDAY ещё не завершён

WorldShop-блок **не содержит координат входа** и не удостоверяет,
что игрок реально пересёк shop trigger либо досмотрел сюжетную сцену.
Его trigger hash служит **идентификатором**, а не игровым событием
«завершено». Порт не должен засчитывать поездку по Paths4000,
приближение к гипотетической точке или проигрывание `SCENE05`
как подтверждённую победу A/B.

Для дальнейшей реализации нужно извлечь адрес/зону
`TRIGGER_CC_CAR_LOT_1` из соответствующих **оригинальных world-ресурсов**,
которых нет в одном GlobalB. Затем подключить достоверное событие
входа/выхода в shop и оригинальные шаги сценки, после чего существующий
атомарный `ug2_prologue_record_verified_finish()` может сохранять
результат. Проверка Ubuntu ARM64/GLES2 CI не заменяет RG40XX H/Mali.
