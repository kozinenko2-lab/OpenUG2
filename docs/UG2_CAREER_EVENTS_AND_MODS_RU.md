# Карьера Underground 2: реальные события и лёгкие моды для H700

## Что делает ветка

Из локального `GLOBAL/GlobalB.lzc` оригинальной ПК-игры OpenUG2
считывает `GCareerRace`, в том числе **TrackID** (`+0x18`),
**тип события** (`eEventBehaviorType` по `+0x0F`), **этап**
(`+0x37`), **число соперников** (`+0x7C`) и **денежную награду**
(`+0x30`). Источник формата: [NFSTools/GlobalLib](https://github.com/NFSTools/GlobalLib)
(лицензия MIT).

**Важная находка на пользовательском оригинале**: `TrackID` напрямую
соответствует номеру маршрута `TRACKS/ROUTES.../PathsNNNN.bin`, который
уже используется нашим парсером городских событий `world.c`.

Примеры:
- `STAGE_1_CIRCUIT_1` → **4013**, Circuit (0), этап 1,
  три соперника, **250** кредитов;
- `STAGE_1_SPRINT_1` → **4101**, Sprint (1), этап 1,
  три соперника, **250** кредитов;
- `S2_CIRCUIT_2` → **4014**, Circuit (0), этап 2,
  три соперника, **300** кредитов.

Внутри `career_event_map.c` разрешение происходит по тройке
`TrackID + stage + event_behavior` и, при необходимости, по явно
выбранному исходному ID. **Повторно используемые маршруты не
приводят к автоматическому выбору самого выгодного события**.

## Что теперь начисляет деньги

Старые условные **500** кредитов из `main.c` устранены. Новая
выплата разрешена только при одновременном выполнении условий:

1. Загружен валидный оригинальный `GlobalB.lzc` и указан
   `--career-save` внутри игрового каталога.
2. Завершена реальная круговая гонка с ИИ; первое место вычисляется
   игровым счётчиком круга/места.
3. ID фактически пройденного `PathsNNNN.bin` совпадает с исходным
   `TrackID`, совпадают этап и категория **Circuit**, событие уникально
   (или явно выбран его исходный ID).
4. Совпадает число реальных соперников с полем оригинала.
5. Событие является обычной гонкой, а не скрытой, SUV, URL, спонсорской
   или многосоставной гонкой. Пока не воспроизведены условия их открытия,
   для них выплат нет.
6. В исходном профиле нет победы по этому ID, в том числе сохранённой
   прежним прототипом по старому идентификатору маршрута.
7. Сохранение `career.dat` проходит успешно.

**Этапы не переводятся автоматически** по временным, придуманным
раньше требованиям: необходимо восстановить реальные условия из
`GCareerStage`, `Sponsor` и игровых миссий.

Для выбора нужного варианта, когда оригинал повторно использует
маршрут, можно указать `--career-race S2_CIRCUIT_2`.
Без выбора неоднозначная гонка не приносит денег.

### Карта / интерфейс

В режиме с исходным `--event NNNN` и `--career-save` выводится
доказанная связь ID карты и исходного события; если нет однозначного
сопоставления, об этом сообщается в логе. В предгоночном меню
для выбранной кольцевой гонки отображается оригинальное имя
и награда, только если сопоставление однозначно.

Нынешние **городские спринты и другие `world_race_start()` события**
могут пройти маршрут по контрольным воротам, но ещё **не** определяют
честно место относительно реальных оппонентов. Поэтому награда
за них пока заблокирована (иначе возникал бы способ получать деньги,
просто проезжая контрольные точки без гонки).

## Модификации без пересборки (GlobalLib-inspired)

На консоли с RAM 1 ГБ не нужен редактор на C#/.NET. Вместо него
добавлен опциональный **текстовый слой переопределения выплат**.
Оригинальный `GlobalB.lzc` остаётся неизменным.

Пример: `openug2/mods/career_rewards.ini`

```ini
# Пример, не распространяемые игровые данные
STAGE_1_CIRCUIT_1=420
S2_CIRCUIT_2=500
```

В `portmaster/OpenUG2.sh` включите переключатель
`ENABLE_CAREER_MODS=1` (изначально он равен 0). Наличие файла
`openug2/mods/career_rewards.ini` обязательно при включённом
переключателе. Для неоднозначных маршрутов можно также задать
`CAREER_RACE_ID=S2_CIRCUIT_2` — точное имя из оригинального каталога.

Альтернатива при ручном запуске из терминала — добавить аргументы:

```sh
--career-save "$GAMEDIR/saves/career.dat" \
--career-mods "$GAMEDIR/mods/career_rewards.ini"
```

Проверяются все имена событий и значения (0–1 000 000).
Неизвестное имя, повторный ключ или неверное число
отклоняют **все** изменения из файла, оставляя оригинальные награды.
Сами игровые ресурсы EA не изменяются.

Это первая часть редактора модификаций. В будущем та же система
может аккуратно поддерживать магазины, доступность автомобилей,
спонсоров и этапы; пока для этих данных нет доказанных правил
применения в игровом движке.

## Проверки

```bash
make career-event-map-test
make career-mods-test
make career-source-test
make ug2-career-file-test
make gles
```

Тесты используют синтетические записи, так что репозиторий
не содержит оригинальных данных EA. Реальный файл проверяется локально,
а запуск/прохождение необходимо проверить на физическом Anbernic
RG40XX H (Allwinner H700, ARM64, SDL2, GLES2, PortMaster).

Результаты сборки CI — это **не** доказательство полноценной
играбельной карьеры.
