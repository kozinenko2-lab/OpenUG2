# Original NFS Underground 2: career events, map and modding via GlobalLib

## Что реально реализовано

Источники форматов: [NFSTools/GlobalLib](https://github.com/NFSTools/GlobalLib),
MIT license (copyright 2020 MaxHwoy & NFS Tools), файлы
`GCareerRace/Functional/Disassemble.cs` и
`Framework/CareerManager/Reading/ReadGCareerRaces.cs`.

Наше программное обеспечение не запускает .NET/Windows Forms на H700.
GlobalLib остаётся настольным инструментом исследования/редактирования;
в игре встроены независимые компактные C99-парсеры и безопасный моддинг
через отдельные конфигурационные файлы.

### 1. События на карте

`GcareerRace.TrackID_Stage1` (16 бит, запись +0x18) соответствует
номеру `TRACKS/ROUTES.../Paths<id>.bin` и `WEvent.id`
уже загруженных событий города. После загрузки
`game/GLOBAL/GlobalB.lzc` порт проверяет оригинальные записи и
сопоставляет их **по стадии и номеру маршрута**.

Данные отображаются в логе `logs/OpenUG2.log` как
`retail map event:`; если на текущем этапе несколько событий используют
один номер, имя/награда НЕ угадываются. `--career-race ИМЯ`
даёт однозначность, если ID действительно принадлежит оригиналу.
Название и награда выбранного маршрута выводятся также
на экране выбора гонки; это лишь предварительный просмотр, а не победа.

### 2. Победа и деньги

`--career-save saves/career.dat` активирует только частное сохранение
OpenUG2, не затрагивая сохранения оригинальной PC игры.

`--career-race STAGE_1_CIRCUIT_1` позволяет явно выбрать
запись, чьё имя содержится в локальном оригинальном GlobalB.
`--circuit ROUTESL4RF/Paths4013.bin` — пример совпадения
RouteID для этой конкретной записи.

Выплата происходит **только** если:
- это кольцевая гонка с поддерживаемой AI-системой;
- совпадают исходное имя, карьерный этап, маршрут, количество реальных
  соперников и число кругов из оригинальной записи;
- игрок пришёл первым;
- запись не была отмечена как выигранная ранее;
- сохранение успешно записано.

Ложная награда 500 кредитов удалена. Доступные виды гонок пока ограничены
AI circuit: у спринтов уже имеются оригинальные ID и суммы призов
для карты, но отсутствует подтверждённый соревновательный финиш
против AI. Solo checkpoint-события пока не награждаются.

**Не завершено:** Retail `GCareerStage` и `Sponsor` требуют
дополнительных правил перехода между этапами; старые
`career_requirements` — прототипные и не используются для
автоматического повышения этапа после настоящей гонки.

### 3. Быстрые модификации на H700 без перекомпиляции

Достаточно обычного текстового файла
`ports/openug2/mods/career_rewards.csv` в UTF-8/ASCII:

```csv
race_id,cash
STAGE_1_CIRCUIT_1,350
```

Это **пример пользовательской модификации**: сумма 350 — предложенная
новая награда, не исходное значение оригинала. В исходной таблице
данной гонки награда составляет 250.

Лаунчер `OpenUG2.sh` автоматически подключает этот файл,
только если он существует. Настройка `CAREER_BALANCE_FILE` доступна
в начале скрипта. `CAREER_RACE` можно заполнить точным ID гонки;
пустое значение допускает только однозначные совпадения.

В C99 файл обрабатывает `src/ug2_career_balance_mod.c`:
- проверяет точное совпадение ID с оригинальным каталогом;
- требует уникальности строк и суммы 0..1000000;
- сначала валидирует *весь* файл; ошибочная строка отменяет импорт
  целиком, оставляя оригинальный каталог без изменений;
- не редактирует `GlobalB.lzc` на SD и не публикует игровой контент;
- никогда не меняет маршруты, этапы, соперников или требования.
- значение `cash=0` отключает получение награды в привязчике
  пока событие не поддерживает нулевую выплату по правилам карьеры.

Файл создаётся человеком либо внешним настольным инструментом.
GlobalLib полезен для создания более сложных модов и экспорта своих
данных; сам C#-редактор в исполняемый файл H700 включать не требуется.
Для полноценного редактирования оригинального `GlobalB.lzc` и других
форматов после резервного копирования можно использовать настольную
GlobalLib; в OpenUG2 предпочитается неразрушающий overlay.

### 4. Проверки и ограничения

Без файлов EA: `make ug2-career-file-test`,
`make ug2-career-binding-test`,
`make ug2-career-balance-mod-test`,
`bash tools/portmaster_mock_test.sh` и ARM64 CI.

Проверки ARM64 Linux CI не заменяют испытаний реального H700/Мali GLES2.
Из оригинального GlobalB прочитаны 2 секции, 232 записи,
225 уникальных ID. До завершения истории Caleb ещё необходимы
гонки разных типов, их AI/результаты, условия спонсоров и магазины.
